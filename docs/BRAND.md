# Studybeat Brand Guide

## Name

**Studybeat** — one word, capital S. Never “Study Beat” in UI.

## Tagline

> Your personal AI-powered study companion that creates the perfect study environment.

Short: **Study smarter. Sound better.**

## Logo

- Wordmark in Outfit Bold / ExtraBold
- Mark: abstract waveform in a circular ocean disc
- Clear space: 0.5× mark height on all sides
- Do not add drop shadows or neon glow

## Color

| Token | Hex | Use |
|-------|-----|-----|
| Ocean Primary | `#1A6B8A` | Buttons, key UI |
| Ocean Soft | `#2E8AAB` | Charts, secondary |
| Accent Teal | `#3ECFB2` | Success, highlights, CTAs |
| Deep Background | `#071820` | App canvas |
| Surface | `#0E2A36` | Panels |
| Text | `#F2F8FB` | Primary text |

Alternate themes: Forest Green, Lavender, Dark Mode, Solar Orange, Midnight Purple, Minimal White.

## Typography

- Display: **Outfit**
- Body / UI: **DM Sans**
- Avoid Inter, Roboto, Arial as brand fonts

## Voice

Calm, encouraging, precise. No hype spam. Coach copy is one sentence.

## Music theme imagery

Prefer real atmospheric references (ocean, forest canopy, library stacks) over abstract purple gradients.
